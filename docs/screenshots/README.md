# Capturas de Pantalla — EcoRoute AI

Este directorio contiene las capturas de pantalla de la aplicación para el informe académico.

## Vistas requeridas

| Archivo | Descripción | Estado |
|---------|-------------|--------|
| `01-dashboard-mapa.png` | Dashboard principal: Mapa Leaflet + Panel de Rutas | Pendiente |
| `02-nuevo-contenedor.png` | Modal Nuevo Contenedor (código, tipo, nivel, coordenadas) | Pendiente |
| `03-reciclaje-gamificacion.png` | Registro Reciclaje + Panel Gamificación (puntos, nivel, recompensas) | Pendiente |
| `04-separacion-guia.png` | Guía de Separación en la Fuente (tarjetas por material) | Pendiente |
| `05-toasts.png` | Notificaciones Toast (éxito, error, info) sobre el mapa | Pendiente |
| `06-dark-mode.png` | Vista completa en modo oscuro | Pendiente |
| `07-ia-proceso.png` | Proceso de desarrollo asistido por IA | Pendiente |
| `08-dashboard-gerencial.png` | Dashboard Gerencial (KPIs, filtros, gráfico por zona, críticos) | Pendiente |

## Instrucciones

1. Ejecutar la aplicación: `npm run dev`
2. Navegar a cada vista y capturar pantalla (1920x1080 recomendado)
3. Guardar como PNG en este directorio con los nombres exactos arriba
4. Las capturas se referencian automáticamente en `INFORME_PROYECTO.md` sección **l)**

> **Nota**: Los nombres de archivo deben coincidir exactamente para que los enlaces en el informe funcionen.
